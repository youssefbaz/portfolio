Motivation Letter Generator Using LLMs and LangChain
This project is a Streamlit-based app that helps users automatically generate personalized motivation letters from their resumes. It uses advanced Large Language Models (LLMs), PDF parsing, and job scraping from APEC to create ready-to-send letters in PDF format.
Tools used: Python, LangChain, Streamlit, PyMuPDF, BeautifulSoup, Selenium
Features: Resume analysis, LLM-based letter generation, job scraping, downloadable PDFs
